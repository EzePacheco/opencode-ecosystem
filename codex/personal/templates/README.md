# Plantilla común opcional de Project Instructions

[project-instructions.md](project-instructions.md) es la fuente durable del método común solicitado. Es autocontenida, product-neutral y opcional: una guía breve de objetivo, límites, aceptación y procedencia puede bastar; Codex inspecciona el repo y elige su plan. El detalle adicional depende de riesgos, contratos y decisiones materiales. No exige un pack, manifiesto, spec o encabezado de controles por rutina.

Esta carpeta no se instala como AGENTS ni configura ChatGPT. Actualizar el archivo no cambia ningún Project live, sus Sources, memoria o acceso. Aplicación y readback de un destino real requieren el alcance correspondiente. No confundir Projects con Pages/Spaces ni inferir acceso entre ChatGPT y Codex.
